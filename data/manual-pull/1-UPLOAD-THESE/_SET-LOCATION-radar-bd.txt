USE "DISCOVER NEW KEYWORDS" — NOT "Get search volume"
LOCATION = Bangladesh   |   ONE run   |   results go in the bd/ SUBFOLDER
========================================

READ THIS FIRST — WHAT THIS BATCH IS AND IS NOT.
This is NOT the money question. Bangladesh AdSense RPM is roughly $0.1-0.5 against $31.50 for US
finance — 60-300x worse per visitor. Even 10,000 BD visits a DAY earns about $30-150/month. This
batch can never reach the $1k/mo target, and it must not be judged against it.

It is here for one reason: class-9-math-bangla is the ONLY content on this site that reliably gets
clicked, so BD is where the course engine can actually be PROVEN to work end to end — real demand,
real ranking, real clicks — while the US batches test whether money is reachable at all.
Kept deliberately small (one run, 8 seeds) so it costs ~5 minutes, not half the session.

STEPS:
  1. Google Ads > Tools > Keyword Planner > "Discover new keywords"
  2. Tab "Start with keywords" — paste batch-radar-bd-01.csv
  3. LOCATIONS = Bangladesh          <- wrong location = wrong volume = wasted pull
  4. Language = Bengali (add English too — students search in both)
  5. Download the CSV into: data/manual-pull/2-DROP-RESULTS-HERE/bd/     <- the bd/ SUBFOLDER

Why bd/ and not the flat folder: the shared volume loader globs ONLY the flat directory, so
Bangladesh numbers dropped there would be read as US demand and corrupt every winnability score on
the site. The bd/ subfolder is invisible to that loader and is read separately by
build-course-radar.py. Never drop a BD export in the flat folder.

The export header may read "Keyword (by relevance)" instead of "Keyword" — the parser handles both.
